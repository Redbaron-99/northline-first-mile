Carrier capacity at peak

Method: trailers needed = loads per day × cycle days, where cycle = transit out + transit back + 1 day to load and unload. Only DC-origin lanes use the owned pool; cross-dock lanes run on carrier equipment. Loads beyond committed capacity go to the spot market at the premium set above.
